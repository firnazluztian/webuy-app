# `@webuy/eslint-config`

Shared ESLint flat configs for WeBuy apps.

| Export | Use |
| --- | --- |
| `@webuy/eslint-config/base` | Shared TS + `no-console` |
| `@webuy/eslint-config/next` | Storefront (`@webuy/web`) |
| `@webuy/eslint-config/react` | Backoffice (`@webuy/bo`) |

See [ADR-0003](../../docs/adr/0003-eslint-quality-gates.md).
